# Packs

A rules pack is a JSON file named after its game system's slug: `srd-5e.json` in
`server/extensions/rpg_systems/packs/`, or in a directory on `VTT_PACKS_DIRS` (separated by `:`).
`load_pack(slug)` reads the first it finds. The `srd-5e` pack is generated by
`tools/foundry-bridge/srd5e.py --pack` and must not be edited by hand: every value is parsed from
the SRD's own text, or the open fifth-edition system's packs, and the bridge stops if the text no
longer says it.

## Keys

| Key                           | What reads it          | What it holds                                                                                                                |
| ----------------------------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `system`, `source`, `license` | everything             | The slug, the rules' source, their licence                                                                                   |
| `test`                        | rpg_dice               | The test: `kind` (`d20-over` or `d100-under`), `die`, `no_sheet_score`, and `advantage` (`dice`, and which to keep for each) |
| `difficulties`                | rpg_dice               | Each difficulty's DC or modifier, and the `default`                                                                          |
| `characteristics`             | rpg_dice, rpg_traits   | The abilities: `slug`, `name`, `short`                                                                                       |
| `skills`                      | rpg_dice, rpg_traits   | Each skill: `slug`, `name`, its `characteristic`, `specialist`, and the source system's `key`                                |
| `skill_ranks`, `proficiency`  | rpg_dice               | What a rank adds, and the Proficiency Bonus by level or CR                                                                   |
| `initiative`                  | rpg_dice, rpg_combat   | Its dice, characteristic and ties                                                                                            |
| `ability_methods`             | rpg_builder            | `standard_array`, `standard_array_by_class` (keyed by the class's compendium UUID), `point_buy`, `roll`                      |
| `creation`                    | rpg_builder            | The steps, and the trait kinds each chooses                                                                                  |
| `npcs`                        | rpg_builder            | Stat blocks (`abilities`, `skills`, `hp`, `ac`, `cr`, `attacks`) and the `generic` one                                       |
| `weapons`                     | rpg_combat, rpg_traits | Each weapon: `slug`, `category`, `melee`, `damage`, `damage_type`, `versatile`, `properties`, `range`                        |
| `attack`                      | rpg_combat             | The ability by `melee`, `ranged` and `finesse`, the `critical` natural and dice, the natural `miss`                          |
| `resources`, `armor_class`    | rpg_traits, rpg_combat | The resource traits a sheet holds; the base AC and its characteristic                                                        |

A system with no `test` in its pack (or no pack) rolls formulas only. A content module's `rules`
can stand in for a pack, in the same shape, for a system whose pack is private.

## Trait templates

`rpg_traits`' seed migrations turn a pack's characteristics, skills, weapons and resources into
trait templates of the system (`005`, `006`), written as the framework's SYSTEM user. A character
holds a characteristic or resource as a value, a skill as a rank, and a weapon as a row.
