# Getting started

Zephyrex VTT is the table where a campaign is played: the map with everyone's tokens, the dice,
the character sheets and the fight. The campaign itself (its characters, places and items) lives
in the wiki, and the VTT puts those on the table.

## Who sees what

There are two roles at a table.

- **The game master** owns the campaign. They see every scene whole, every token (hidden ones too),
  and run the fight. Anything only the GM may do answers anyone else as if it weren't there.
- **A player** plays one or more characters: their own (the character's player in the wiki) or the
  ones a table seat gives them. They see what their character's token can see, and move and roll
  for their own characters only.

The server decides all of this. The screens only choose which buttons to show.

## The rules

Every rule comes from the campaign's game system, through its rules pack: how a test is rolled,
what a difficulty is, how a character is built, how an attack hits. The public VTT carries the
fifth-edition SRD 5.2. A campaign on a system with no pack can still roll dice formulas. See
[Game systems and packs](?path=/docs/vtt-guide-7-game-systems-and-packs--docs).
